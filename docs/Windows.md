# Windows PowerShell Development Setup

## Overview
PowerShell 7+ (`pwsh`) on Windows 11+ provides full access to Winget package management and Windows terminal integrations.

## Profile Location
`$HOME\Documents\PowerShell\Microsoft.PowerShell_profile.ps1`

## Installation
Run as Administrator:
```powershell
.\starter-installer.ps1
.\setup-profile.ps1
```
